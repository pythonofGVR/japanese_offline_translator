# v1.1.0 改进与发行验收

日期：2026-11-17。发行页：https://github.com/pythonofGVR/japanese_offline_translator/releases/tag/v1.1.0

## 功能

1. CPU 或优先 NVIDIA CUDA GPU 可选。无兼容设备、驱动/运行库不可用、显存不足或 GPU 推理失败时自动回退 CPU；日志显示实际设备与原因。单条重译使用当前选定的设备和推理参数。
2. 线程数 1–min(32,逻辑处理器数)，默认 min(4,上限)；搜索宽度 1–10，默认 3。UI 和后端共同限制，历史配置异常值会在恢复时规范化；提供恢复默认参数按钮。
3. 新文件编辑页可直接打开字幕、TXT、Markdown、DOCX，无需原文或校对记录。支持保存/另存为、自动备份、外部修改冲突保护、字幕结构保护、DOCX 基本样式保留，并同步已有校对记录。
4. 完整离线安装文件通过 GitHub Release 分发，包括两个模型、分词器、CPU/GPU 运行库、VC++ 依赖和许可。安装文件采用四个数据卷，未省略模型或改成在线下载。
5. 本地清理将在公开发布和回下载验证通过后执行：保留运行应用、完整离线安装文件、必要说明及 Git 历史；开发源码通过 Git sparse-checkout 从工作树收起，仍可恢复。原字幕、用户提示文档、用户配置与翻译结果不删除。

## 安装文件

下载同一版本的 JapaneseTranslatorSetup.exe、JapaneseTranslatorSetup-1.bin、-2.bin、-3.bin、-4.bin，放在同一目录再运行 EXE。SHA256SUMS.txt 覆盖所有安装文件及安装指南；具体大小和哈希见 v1.1-github-verified.json。每个资产均小于 GitHub 2 GiB 限制。

GitHub 默认 Source code ZIP 不含大模型，不是应用安装包。源代码与构建脚本在任务分支和版本标签中保留。

## 设备、离线范围与限制

本机 Windows 11 x64，i9-13900H，约 32 GB 内存，RTX 4060 Laptop GPU 8 GB，驱动 566.14。GPU 运行使用 int8_float16，CPU 使用 int8。cuBLAS 12.6.4.1 的两个允许再分发 DLL 随包提供；本文本翻译模型不需要 cuDNN 或完整 CUDA Toolkit。

冻结和安装验证清除了 Python/Qt/CUDA 开发环境变量，PATH 仅保留 Windows System32；进程内禁止 Python socket 联网。没有关闭整机网络或对原生库做防火墙隔离。没有第二台实体 Windows 或可用 Windows Sandbox/Hypervisor，因此不能声称已覆盖所有 Windows/硬件/驱动组合。

目标为 Windows 10/11 x64、CPU 至少 SSE 4.1；建议 8 GB 可用内存和 6 GB 磁盘空间。GPU 为可选功能，无可用 GPU 时使用 CPU。机器翻译仍会误译，未实现 OCR、跨字幕上下文推理和完整术语一致性约束，需人工校对。
