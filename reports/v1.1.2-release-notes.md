# v1.1.2：修复 Windows 界面启动失败

修复 `ImportError: DLL load failed while importing QtCore: 找不到指定的程序`。

根因是构建环境中的 Poppler ICU 78 被误打包成 `icuuc.dll`，与 Qt 需要的 Windows 系统 ICU 接口不兼容。本版本排除第三方 ICU，启动前明确加载 System32 的 ICU；升级安装会清除旧版遗留的两个冲突文件。无需手动复制 DLL，也不修改 Windows 系统文件。

新增正式 EXE 的原生窗口验收，检查 Windows 平台插件、主窗口、实际翻译、校对保存和译文编辑。CPU、GPU、无 GPU 回退均分别验证。此前仅测打包后翻译路径、未覆盖窗口启动的验收漏项已补齐。不带测试参数的正常启动也已在实际桌面中确认。

完整离线安装：下载本页 `JapaneseTranslatorSetup.exe` 和所有 `JapaneseTranslatorSetup-*.bin`，放在同一目录，再运行安装程序。`SHA256SUMS.txt` 可核对完整性。GitHub 自动生成的 Source code ZIP 是开发源码，不含模型。

安装包包含两个 M2M100 INT8 模型、分词器、Python/Qt/CPU 运行库及 NVIDIA cuBLAS。安装和翻译无需 Python、CUDA Toolkit、API Key 或网络。适用于符合使用说明要求的 Windows 10/11 x64；可选 NVIDIA GPU 需有兼容 CUDA 12 的系统驱动，不可用时回退 CPU。

保留 v1.1.1 的 SRT 失败隔离、有限重试、最多 42 个可见字符的单行原文兜底、具体失败原因、只输出译文和应用内编辑功能。用户原字幕、配置与缓存不会被上传。机器翻译仍需人工语义校对。

验收包括 66 项回归测试、正式 EXE/安装版/GitHub 下载版的 CPU/GPU/回退翻译与真实窗口检查，以及旧冲突 DLL 残留的升级测试。完整分卷重新下载后逐段及整体核对 SHA-256，再实际安装验证。尚未在第二台实体 Windows 上测试。
