# v1.1.1 acceptance

Source unit/regression suite: 63 passed. Native Windows Qt GUI validates actual GPU worker, pause/resume, review save, single-row retranslation, standalone file editing/backup and visible parsing-error details.

Three private user SRTs were processed completely with both local models under denied Python sockets. Reports publish only anonymous counts and input hashes, never dialogue or translations. Original bytes and all cue labels/timings remain unchanged. Every output exists, contains no empty cues, and has only translated SRT files beside it. Fallbacks have no hard line breaks and at most 42 visible code points including ellipsis.

| Sample | Cues | Fast fallback | Quality fallback |
|---|---:|---:|---:|
| 1 | 846 | 12 | 7 |
| 2 | 674 | 13 | 7 |
| 3 | 1015 | 11 | 9 |

Fallback includes unknown-model-token detection, residual kana, clearly abnormal length, decoder failures or invalid controls after finite retries. A whole cue containing a failed segment retains a bounded original; the full original and detailed reason stay in local application-data reviews. Completion means the file was saved, not that every sentence is semantically correct. Spot checks found residual semantic errors, especially on short fragments and noisy input; human review remains required.

Original v1.1 behavior reproduced failure on all three inputs: 23, 37 and 38 cue-level format rejections respectively could abort the whole file. Model-generated <unk> tokens were one confirmed cause. New behavior isolates these failures and writes valid output.

Final release verification is recorded separately in v1.1.1-frozen-*.json, installed-mode reports and v1.1.1-github-verified.json. Frozen smoke includes a deliberate decoder error to verify saved bounded originals and concrete reasons in the packaged code.

Compatibility scope: Windows 11 x64 host, Intel i9-13900H, NVIDIA RTX 4060 Laptop (8 GB), driver 566.14; no second physical Windows host or Windows Sandbox. Tests deny Python socket connect/connect_ex/create_connection/getaddrinfo before loading models; native libraries and the whole OS are not firewall-isolated.
