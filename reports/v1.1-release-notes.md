# 日文离线翻译器 v1.1.0

## 下载后可离线安装的完整应用

下载本页 Assets 中的 `JapaneseTranslatorSetup.exe`、**所有** `JapaneseTranslatorSetup-*.bin` 及 `SHA256SUMS.txt`，放到同一个文件夹，再双击 EXE。安装数据包含两个 M2M100 模型、分词器、CPU/GPU 运行库和 VC++ 依赖；分卷仅为符合 GitHub 单文件大小限制，不能遗漏任一 .bin。

`Source code.zip / tar.gz` 是开发源码，不包含大模型，不能替代完整安装文件。

## 本次改进

- CPU / 优先 NVIDIA CUDA GPU 可选；无兼容 GPU、驱动/运行库不可用或 GPU 推理失败时自动回退 CPU，并记录实际设备与原因。
- 线程数限制为 1–min(32,逻辑处理器数)，默认 min(4,上限)；搜索宽度 1–10，默认 3；提供恢复默认参数。后端也校验范围。
- 新增“文件编辑”页，独立打开字幕、TXT、Markdown、DOCX，无需原文或校对记录；支持保存/另存为与自动备份，保护字幕结构并保留 DOCX 基本格式。
- 完整安装程序支持在不安装 Python、CUDA Toolkit、不提供 API Key、不联网下载模型的情况下使用。

## 验证范围

53 项自动化测试通过；CPU、RTX 4060 GPU、模拟无 GPU 三种模式，冻结 EXE 和实际安装后均各通过 26 项离线检查，包括双模型、字幕与文档、独立文件编辑与备份。断网验证禁止 Python socket 连接，未关闭整机网络。

Windows 10/11 x64、CPU 至少 SSE 4.1，建议 8 GB 可用内存、6 GB 磁盘空间。可选 GPU 仅支持 NVIDIA CUDA，需兼容 CUDA 12 的驱动；无可用 GPU 时使用 CPU。Intel/AMD GPU 不提供本版本 GPU 加速。没有独立的第二台 Windows 或干净虚拟机，不能声称已覆盖所有硬件/驱动组合。

翻译仍需人工校对，未实现 OCR 和跨字幕上下文推理。详见安装文件中的使用指南和本页的验收报告。
