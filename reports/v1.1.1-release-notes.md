# v1.1.1：字幕失败恢复与可靠保存

- 修复模型输出未知词、格式校验失败导致整个 SRT 无法保存的问题。任务列表直接展示失败原因，选中后可复制完整详情，双击失败任务可打开原因对话框。
- 推理批次失败会隔离到单句并有限重试。最终无法翻译的字幕保留单行原文，最多 42 个可见字符（含省略号）；校对记录保留完整原文和具体原因。
- 翻译目标目录仅生成译文，不复制或移动原字幕，不再生成含原文的校对 JSON。校对记录保存在本机应用数据目录；旧版记录仍可读取。
- 保留 CPU / NVIDIA GPU 选择、GPU 不可用回退 CPU、参数范围和应用内译文编辑。

完整离线使用：下载本页 `JapaneseTranslatorSetup.exe` 和全部 `JapaneseTranslatorSetup-*.bin`，放到同一个文件夹，再双击安装。`SHA256SUMS.txt` 可校验文件完整性。请勿将 GitHub 自动生成的 Source code ZIP 当成安装包；它不含大模型。

包含两个 M2M100 INT8 模型、分词器、Python/Qt/CPU 运行库、NVIDIA cuBLAS。安装与翻译无需 Python、CUDA Toolkit、API Key 或网络。Windows 10/11 x64，CPU 至少 SSE 4.1；GPU 为可选 NVIDIA CUDA GPU，需要兼容 CUDA 12 的系统驱动，否则使用 CPU。

验收包括三个真实本地 SRT 的完整翻译与保存、原文件哈希不变、序号和时间轴保持、单行原文上限、输出目录仅译文，以及冻结版、安装版、GitHub 下载包的 CPU/GPU/无 GPU 回退。用户字幕与译文不上传；公开报告仅含匿名指标与文件哈希。

机器翻译仍需人工语义校对。跨机安装需求通过完整依赖打包和隔离目录安装验证；未在第二台实体 Windows 电脑上测试。离线测试禁止 Python socket 连接，不等同于全系统防火墙隔离。

验证数据：63 项回归测试通过；三个样例分别为 846、674、1,015 条。快速模型保留原文 12、13、11 条；质量模型保留原文 7、7、9 条，均成功保存完整文件。CPU、GPU、模拟无 GPU 的冻结和安装验收每组 27 项。
